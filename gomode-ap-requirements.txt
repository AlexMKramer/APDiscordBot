# Archipelago 0.6.7 logic dependencies for the go-mode analyzer venv (installed in the
# Dockerfile into /opt/ap-venv, used by the analyzer subprocess via GOMODE_AP_PYTHON).
#
# This is a validated SUBSET of Archipelago's own requirements.txt. It omits:
#   - kivy / kivymd : GUI, never needed to build world logic
#   - Pymem         : Windows-only; a world that needs it just reports "unsupported" on Linux
#   - cython / cymem: optional C speedups; the pure-Python fallback is used
# and ADDS attrs, which AP worlds import (`from attr import ...`) but AP only pulls in
# transitively. Versions pinned to a known-good AP 0.6.7 environment.
#
# Worlds import some things at load time that aren't in AP's list:
#   - setuptools (<81, still ships pkg_resources): Pokemon Emerald, Pokemon FRLG, Paper Mario
#   - requests: FFMQ, Messenger, OSRS, Super Metroid
#   - dolphin-memory-engine: Metroid Prime (its Dolphin client)
# A world whose dependency is missing reports "unsupported"; add the dependency here.
# (Not added: pyevermizer for Secret of Evermore, zilliandomizer for Zillion.)
#
# NOTE: requires Python >= 3.11 (AP 0.6.7 uses typing.Self) -- the Dockerfile uses python:3.12.
